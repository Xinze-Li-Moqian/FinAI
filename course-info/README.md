## Learning objectives

The course uses financial AI case studies to cover reinforcement learning, machine and deep learning for structured data, text and image processing, and LLM trading and asset management. Applications include trading, asset allocation, derivative pricing and hedging, risk management, fraud detection, credit assessment, and financial text analysis.

Students are expected to understand methods and their appropriate uses, execute and explain Python / Jupyter workflows, rerun cases with fresh data or a subset of the original data, add a small experiment, and evaluate model selection bias and overfitting critically. The syllabus asks for basic programming skills, some familiarity with financial terminology, and an interest in practical applications.

## Assessment and deliverables

| Component | Weight | Main deliverables |
|---|---|---|
| AI-Agent / Generative AI homework | 10% | A structured Markdown knowledge base for an investment channel, with evaluation metrics, produced through the prompt, generation, and evaluation workflow |
| First case assignment | 45% | A 45-minute presentation, at least 30 PowerPoint slides, accompanying script, notebook and data, a case rerun, and a small experimental extension |
| Second case assignment | 45% | The same deliverables as the first case assignment |
| Final project alternative | 90%, replacing both case assignments | One final project and presentation; the syllabus points to Case 63, Leveraging LLMs for Sentiment Analysis in Trading |

**The administrative document lists the tentative 10% homework plus two 45% presentations scheme and does not mention a 90% final project.** The alternative in the table comes only from the syllabus. Its availability this term, selection process, and scope require instructor confirmation; an unrestricted choice between the two routes has not been confirmed. Both documents allow a possible change to three 30-minute presentations depending on class size. Individual presentation dates are not yet confirmed.

Each case presentation also needs at least a couple of slides extending the discussion beyond the supplied material, such as a new use, critique, comparison, or unexplored implication. Students must answer questions about both theory and code. See the [presentation checklist](../assignments/presentations/REQUIREMENTS.md) for detailed requirements and preparation status.
