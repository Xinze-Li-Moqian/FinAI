需要注意：

- 出版社 README 的章节编号与教师材料／文件编号不完全一致；用课程 Case 44、书籍章节标题和具体 Notebook 文件共同定位。
- `7.1` 虽叫 Q-Learning，实际实现有 Keras 神经网络。我们的表格版本是另写的预习实验，不能视为对原版训练的复现。
- `7.1` 原文件最后有单独的 `£` 代码单元；原样 Run All 会遇到语法问题。原版保留不动，修订应在工作副本记录。
- 代码使用旧 Keras 导入与优化器接口，Catch.reset 中混合标量和数组的构造也需要检查现代 NumPy 兼容性。
- 交易例子从本地股票 CSV 路径读取数据，并要求收集 100 个股票序列；该数据没有包含在这三个 Notebook 中。
- 交易环境使用历史收益窗口和滚动收益／波动比作奖励。需要审查可观测信息、奖励的历史依赖、数据划分、仓位语义与成本，才能确定正确的复现实验。

以上是静态初查，不是完整代码审计或已解决的兼容性报告。先读清楚模型，再选择固定旧环境或记录明确的兼容性迁移。
