## Coverage

The archive covers attachments and linked companion packages received through **2026-09-18**. It is not a complete collection of everything that may be issued during the semester. Later announcements, recordings, and Quercus-only materials still need to be collected as applicable.

The published snapshot originally contained 1,614 material files and 82 reading-layer files. Those are file counts, not lecture or book counts. Instructor sample outputs have not been reproduced, and the supplied model API pipeline has not been executed for this coursework.

Three earlier archives are provided unchanged. The DeepSeek companion archive was rebuilt as a sanitized ZIP excluding credentials and runtime caches; `.env.example` is a configuration template. Publication changes and checksums are recorded in the manifest. Personal correspondence and private administrative records are excluded. Instructor attribution and third-party rights are retained.
