I had to set the python interpreter because openai was not loading
Go to Tools → Preferences → Python interpreter
Select "Use the following Python interpreter"
Browse to your target python.exe, which is typically at:
Windows: C:\Users\<you>\anaconda3\envs\<env_name>\python.exe  (env_name=deepseek_api)
Click OK and restart Spyder when prompted
close and open Spyder
