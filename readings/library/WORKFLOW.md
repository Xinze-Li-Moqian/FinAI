# Organization and reading workflow

Keep original documents, reading copies, and personal analysis separate. Use Markdown for searchable reading and discussion, BibTeX for references, and LaTeX or Lean when precise definitions or proofs are needed.

Conversions retain text, images, and page navigation but may not reconstruct the original slide layout. Open the original when checking equations or diagrams. Source versions and any changes required for publication are recorded in the material manifest.

Preliminary code reviews and research proposals are not execution results or formal proofs. Each subsequent study should explain the relationship between requirements, checkers, tests, and proofs.

## File ownership

- Course navigation, homework, presentations, personal notes, and research: [course workspace](../../README.md).
- Received attachments and instructor sample output: [original materials](../../materials/README.md).
- Converted documents, conversion provenance, concepts, and references: this reading library.
- Current work and blockers: [Part 1 progress](../../assignments/generative-ai/part1/README.md#current-progress).

Follow the [organization guide](../../course-info/ORGANIZATION.md) when adding new material. Keep conversion manifests and document assets beside their reading copies.
